Questions to ask a drone workshop facilitator

By YANAPublished 27 October 20263 min read

In this guide

  2. Review how they explain uncertainty
  3. Discuss supervision and stopping
  4. Example: request a short teaching sample
  5. Put credentials and scope in the proposal
  6. Practical activity
  7. Questions
  8. References

Ask a prospective facilitator to explain the proposed learner tasks, relevant experience, equipment plan and conditions for stopping an activity. Request evidence for any qualification they advertise. Technical confidence alone does not establish teaching suitability, and a workshop attendance document should not be confused with a pilot qualification.

Match experience to the task

An introductory component lesson and a firmware development session require different preparation. Describe your learners and objectives before asking for a generic profile. Request examples of relevant teaching materials or a sample explanation, where available. If someone cites previous delivery, ask what they personally did and whether any reference can be shared with permission. Do not infer institutional endorsement from a photograph.

Review how they explain uncertainty

A useful facilitator should distinguish an observed fact from a proposed specification and know when to consult documentation. Ask what they would do if a component label disagreed with a diagram. Look for a process of checking, recording and escalating rather than improvising confidently. This is especially relevant when learning equipment combines parts from different suppliers.

Discuss supervision and stopping

Ask which activities learners can perform, which need direct supervision and which are demonstration-only. Request the decision process for pausing an unsuitable activity. A good plan includes alternatives that still produce learning evidence. Do not interpret an instructor’s willingness to fly as proof that a proposed location or operation is permitted. The host and provider need clearly assigned responsibilities.

Example: request a short teaching sample

Give the prospective instructor a simple prompt: explain the difference between an ESC and a flight controller to a beginner using a diagram. Then ask how they would check understanding. A learner-generated comparison or question can reveal more about teaching approach than a slide deck full of technical vocabulary. The exercise is a suggested selection tool, not a certification test.

Put credentials and scope in the proposal

List the actual facilitator, relevant qualifications if verified, assistants and practical limits before announcing professional-led training. For a YANA enquiry, these delivery details remain to be confirmed in writing. Cornell’s course-design guidance provides useful background on aligning activities with learning goals; it does not endorse a particular provider. Treat professional titles and qualification claims as facts requiring evidence.

Ask how the facilitator would respond to a question outside the agreed scope. A clear escalation route and willingness to check a source are useful selection evidence when the host cannot independently evaluate every technical statement.

  • Ask for task-relevant teaching evidence.
  • Verify advertised qualifications directly.
  • Confirm the named facilitator and assistants.
  • Agree supervision boundaries and fallback lessons.

Build a facilitator comparison sheet

  1. Write the same five scope questions for each candidate.
  2. Record evidence supplied rather than assigning scores from impressions.
  3. Identify unanswered questions before accepting a delivery proposal.

Questions

Does workshop attendance make someone a pilot?

No such qualification should be inferred. Any qualification claim requires a clearly identified programme and independently verified conditions.

Can YANA provide professional-led training?

You can enquire about that format. The named facilitator, credentials, content, availability and commercial terms need confirmation in a written proposal.
