Describe the learners, intended outcomes, host resources and preferred dates, then ask YANA for a scoped partnership proposal. Discuss hands-on drone-making, development learning or professional-led training as requested formats. Facilitator credentials, activities, duration, group size, location, equipment and charges must be confirmed in writing before the partnership is promoted.

Explain the partnership purpose

State whether your college, robotics club or makerspace wants an introductory event, a course-linked activity or a series of discussions leading to a defined workshop. Identify what learners should produce. Avoid using partnership as a vague substitute for a delivery agreement. Both sides should understand the educational goal and who is responsible for approving the format.

Describe the host contribution

List available rooms, computers, equipment, staff coordination and learner background. Mark resources that have not been checked. Include the city and access requirements so feasibility can be discussed without claiming an established service area. A host can request a particular location, but YANA’s ability to deliver there remains a matter for confirmation rather than a website assumption.

Ask about the delivery contribution

Request the named facilitator, relevant experience and evidence for any professional credentials advertised. Ask which activities are learner handling, supervised assembly, development discussion or demonstration. Do not promise that every participant builds or flies a complete drone. The written proposal should separate possible options from tasks the provider can actually deliver with the agreed resources and supervision.

Example: a makerspace enquiry

A makerspace may want members to understand quadcopter subsystems and prepare a documented assembly plan. It offers bench space and a coordinator but asks YANA to propose suitable teaching equipment and facilitator arrangements. The first response can define a bounded event before either side announces dates or outcomes. This is an enquiry example, not evidence of an existing YANA client or delivered programme.

Agree public wording and next steps

Confirm the agenda, equipment ownership, charges, host responsibilities and fallback conditions. Agree permission for photographs, participant information and logo use before promotion. The ATL drone module provides educational context, not affiliation or endorsement. Any aircraft operation needs separate current assessment and permissions. Email hello@naadix.xyz with the brief, then retain the final scope so future coordinators can distinguish agreed delivery from initial discussion.

Name one contact on each side to maintain the agreed scope. If the host later changes attendance, venue or intended activities, review the delivery implications before updating publicity so the public description continues to match what can be provided.

  • Name the host, learners and learning outcomes.
  • List available and unconfirmed resources.
  • Request facilitator details and practical boundaries.
  • Agree written delivery terms and publicity permissions.

Draft a partnership brief

  1. Write the learner goal and host contribution.
  2. List the delivery questions YANA needs to answer.
  3. Mark every proposed public claim that requires confirmation first.

Questions

Can we enquire about professional-led training?

Yes. Request that format and ask for the actual facilitator, credentials and delivery scope to be confirmed in the proposal.

Does an enquiry establish a partnership?

No. Confirm the scope, responsibilities, availability and public wording before presenting the arrangement as agreed.
