What to put in an institutional drone workshop enquiry

By YANAPublished 27 October 20263 min read

In this guide

  1. Explain the educational purpose
  2. Describe learners and resources
  3. Ask about the delivery team
  4. Example: replace a vague request
  5. Request a complete response
  6. Practical activity
  7. Questions
  8. References

Describe your institution, learner background, objectives, approximate attendance, location and preferred dates. Add the practical tasks you want to discuss and the resources you can provide. Mark open questions rather than guessing. Ask for a written proposal that separates confirmed delivery details from optional activities.

Explain the educational purpose

Write why the workshop is useful now: an introductory club event, a course-linked investigation or preparation for a longer project. State what learners should produce afterwards. A specific output, such as an annotated quadcopter system diagram, helps a provider assess scope more accurately than a broad request for advanced drone training. Keep ambitious future projects separate from the first session’s deliverables.

Describe learners and resources

Include their study level and relevant experience, not only headcount. State whether they have computers, tools or any existing equipment and whether those resources have been checked. Mention access requirements that affect participation. You do not need a finished technical specification to make an enquiry; an honest description of what is known is more useful than unsupported assumptions.

Ask about the delivery team

Request the named facilitator, relevant credentials where claimed, assistants and supervision arrangements. Ask which activities are explanation, learner handling or demonstration. If you want professional-led drone-making and development training, describe that intention without assuming a standard programme exists. YANA can discuss a partnership proposal, with format, availability and delivery details confirmed in writing.

Example: replace a vague request

Instead of asking for a workshop for our students, write that a robotics club wants beginners to identify major quadcopter subsystems and document a supervised inspection. State the approximate group size, available room and computer arrangement, then ask which practical tasks are feasible. This gives the provider a concrete starting point while leaving room to recommend a different format.

Request a complete response

Ask the proposal to state duration, group size, equipment ownership, materials, exclusions, location, charges and host responsibilities. Request a fallback if a demonstration cannot proceed. Cornell’s outcome-setting guidance is useful background for the educational part of the brief; the proposed enquiry structure is a practical planning tool. Keep any subsequent changes in the same written record.

  • Include institution, city, role and contact email.
  • State learner experience and desired outputs.
  • Describe available venue and equipment.
  • Request named delivery staff and itemised terms.

Draft a concise enquiry email

  1. Write the learning goal in the first sentence.
  2. Add known resources and unresolved constraints in separate paragraphs.
  3. End with a request for a scoped written proposal and suitable next steps.

Questions

Must the dates be final before contacting YANA?

No. Share preferred dates and flexibility, then confirm availability through the proposal process.

Should we ask for a flying demonstration?

You can request it for discussion. It remains a separate activity requiring suitable conditions, responsibilities and current permissions.
