Thrust and weight: a classroom force diagram for quadcopters

By YANAPublished 27 October 20263 min read

  4. Tilt changes the useful components
  5. State the limits of the diagram

  7. Questions
  8. References

Weight acts downward, while rotor thrust acts along the combined rotor force direction. In a simplified level hover, total upward thrust balances weight. A tilted vehicle needs consideration of vertical and horizontal components. This is a force-balance model, not a prediction of a particular drone’s payload or flight time.

Use forces rather than motor percentages

A motor command percentage is not a force measurement. The same command can correspond to different thrust under different voltage, propeller and airflow conditions. Start a worksheet with forces measured in newtons. Keep mass in kilograms and weight as mass multiplied by gravitational acceleration. This prevents a common error in which a mass value is added directly to a force.

Balance is a special condition

For an illustrative 1 kg object, taking gravitational acceleration as 9.81 metres per second squared gives a weight of 9.81 newtons. Four equal upward forces would each contribute about 2.45 newtons in a simple static balance. These are invented classroom values, not measured YANA data. They help students check the arithmetic and distinguish a model from a specification.

A net force changes velocity

If the combined force is unbalanced, the object accelerates. An upward imbalance does not mean that altitude instantly jumps; velocity changes over time. Conversely, zero acceleration does not always mean zero velocity. A paper timeline showing position, velocity and acceleration makes this distinction more useful than a single snapshot of a drone apparently hanging in the air.

Tilt changes the useful components

A tilted thrust vector has both vertical and horizontal components. Only its vertical component directly opposes weight in the simplified diagram. Students can draw a vector at an illustrative angle and project it onto two axes. They should keep the total thrust constant for this drawing, then observe that its vertical component becomes smaller. Actual vehicle behaviour also involves drag and controller responses.

State the limits of the diagram

NASA’s force explanations support the distinction between force magnitude and direction. A classroom free-body diagram deliberately omits rotor interactions, changing airflow and electrical limits. Include an assumptions box so the result cannot be mistaken for a payload rating. A useful answer identifies which forces were considered and what measurements would be needed to improve the model.

  • Use consistent SI units.
  • Label every vector direction.
  • Separate a balanced force from a stopped vehicle.
  • Identify illustrative values explicitly.

Draw three versions of the same vehicle

  1. Draw a level balanced model, a level model with an upward net force and a tilted model with unchanged total thrust.
  2. Use the illustrative 1 kg mass and write the weight calculation beside all three diagrams.
  3. Ask teams to predict acceleration direction rather than claim an exact travel distance.
  4. Compare answers and list the extra information required to calculate position after two seconds.

Questions

Can this calculation establish how much a drone can carry?

No. A payload claim needs tested propulsion, thermal, structural and control margins under defined conditions. A static force sketch does not supply that evidence.

Does hovering mean the motors produce no force?

No. In the simplified model their upward thrust balances the downward weight, producing approximately zero net vertical force.
