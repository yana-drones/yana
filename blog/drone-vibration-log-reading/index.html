Read drone vibration evidence without jumping to a repair

By YANAPublished 27 October 20263 min read

In this guide

  1. Identify which vibration evidence is available
  2. Look for context and configuration changes
  3. Separate magnitude from frequency content
  4. Consider the entire transmission path
  5. Write a hypothesis and a discriminating observation
  6. Practical activity
  7. Questions
  8. References

Vibration analysis starts with the exact logged quantity and processing method. A vibration metric, raw accelerometer trace and frequency spectrum answer different questions. Compare documented evidence with installation observations, then form testable hypotheses. Do not copy thresholds or filter settings between systems or assume a smoother graph proves a mechanical repair.

Identify which vibration evidence is available

A processed summary can show one aspect of sensor disturbance, while raw samples support different analysis. ArduPilot’s vibration documentation also discusses clipping, which is not the same as ordinary variation in a plotted line. Record field identity, units, logger settings and time window before comparing datasets. A label such as vibration alone is too broad.

Look for context and configuration changes

Tie each recording to a known hardware arrangement and observation period. If two datasets use different mounts, sensor settings or analysis windows, list those differences first. A classroom comparison can use supplied recordings with one known difference. The goal is to reason about evidence, not to create an unnecessary powered test or make unreviewed changes to a real aircraft.

Separate magnitude from frequency content

A time trace shows how a value changes over time, while a spectrum represents frequency-related information under defined processing choices. Two signals can have similar overall variation but different dominant frequencies. Use invented waveforms on graph paper to illustrate this. Any real frequency attribution needs correct sample rate, analysis method and additional evidence linking it to a source.

Consider the entire transmission path

A vibration concern can involve a source, structural path, mount or cable connection. A log alone may not identify which part dominates. Combine it with a documented disconnected inspection and list competing explanations. More foam or a filter adjustment is not automatically the appropriate next action. Actual remedies require system-specific guidance and appropriate expertise.

Write a hypothesis and a discriminating observation

A useful report says what changed, which explanation is plausible and which further evidence would distinguish it from alternatives. Preserve the baseline and avoid universal claims from a single recording. The exercise should end with an evidence table rather than an operational acceptance decision. No specific YANA vibration performance or installation quality is asserted by these educational examples.

  • Name the exact metric and processing stage.
  • Keep clipping separate from normal variation.
  • Record sample rate and analysis window.
  • Link logs to known installation conditions.

Compare two supplied vibration summaries

  1. Use fictional summaries with the same units and window but different mount labels, clearly marked as invented.
  2. Ask students to describe the difference without naming a failed part.
  3. Add a photograph of a disconnected classroom mount with a taut string bypass and discuss one plausible explanation.
  4. List an alternative explanation and the additional observation needed to distinguish it before proposing any real change.

Questions

Should I copy a vibration threshold from any tutorial?

No. Use the relevant stack’s definitions and guidance for the actual system. A numerical threshold without context can be misleading.

Does a frequency peak identify one motor automatically?

No. Frequency evidence needs context and corroboration. Several sources or processing effects can produce superficially similar features.
