How to request a useful educational drone quote from YANA

Tell YANA who will use the drone, what they want to learn and which resources your institution already has. Ask for the final configuration, itemised package, evidence and service terms in writing. The proposed F450/Pixhawk 2.4.8 combination is a starting point for discussion, with other details remaining subject to confirmation.

Describe the learner and purpose

Include your institution or group, role, city and relevant background. Explain whether the aim is component learning, supervised assembly, documentation or another bounded educational task. A specific purpose helps identify what needs to be discussed. Avoid requesting every possible feature by default; it can make a straightforward learning purchase harder to scope and support.

State existing resources honestly

Mention available computers, tools, storage and supervision, marking anything not yet checked. If the institution already owns related equipment, provide identifiers rather than assuming compatibility. You do not need a complete technical design to enquire. A clear account of known resources and open questions is more useful than a confident list assembled from unrelated product pages.

Ask for the full configuration

Request the final component list, assembly state, software context and documentation. Ask which accessories are included, excluded or optional. YANA currently proposes one educational quadcopter using an F450 frame and Pixhawk 2.4.8 controller. Flight time, range, payload, package contents, price, delivery and warranty should remain unconfirmed until explicitly supported in the agreed proposal.

Example: a focused first message

A college robotics coordinator might explain that beginners need to study subsystem relationships on a shared assembly, that the host has computers but needs equipment guidance, and that a component demonstration is preferred before purchase. The coordinator can ask for a proposed configuration and itemised quote. This leaves room to clarify needs without falsely implying the host already has an approved operational programme.

Separate product and workshop enquiries

If you also want a hands-on workshop or professional-led training, say which outcomes and audience you have in mind. Ask for the facilitator, duration, group size, location and service terms separately. Cornell’s outcome-setting guidance provides educational planning context; the enquiry should still request a concrete commercial response. Draft a quote enquiry

  1. Write your main educational objective in one sentence.
  2. Add the proposed equipment and the facts needing confirmation.
  3. Request a component demonstration or clarification call where useful.

Questions

Is a published price available in this guide?

No. Ask YANA for a custom written quotation based on the final configuration and agreed scope.

Can an individual student enquire?

Yes. Explain your learning goals, experience and available resources so the discussion can address the actual use case.
