Motor KV explained: what the number can and cannot tell you

By YANAPublished 27 October 20263 min read

  2. Use a hypothetical no-load estimate

  8. References

A motor’s KV notation commonly describes a speed constant expressed in revolutions per minute per volt. It is not a power rating or a guarantee of loaded speed. Interpret it with the motor’s full datasheet, voltage limits, thermal conditions and tested propeller combinations rather than selecting a motor from KV alone.

Read the unit before comparing the value

The K in common motor KV notation does not mean kilo in the same way as a kilovolt unit. Write the stated unit, RPM per volt, beside the number in your inventory. PX4’s versioned parameter reference uses that unit for a motor speed-constant field. That reference explains notation; it does not supply the actual constant of an unidentified motor.

Use a hypothetical no-load estimate

For a simplified classroom calculation, a fictional 800 RPM-per-volt constant multiplied by 10 volts suggests 8,000 RPM under the assumed no-load model. This is not a recommended motor, supply or experiment. The arithmetic illustrates proportional reasoning only. Real operating speed depends on load, electrical losses, control behaviour and the actual motor’s characteristics.

A propeller changes the operating problem

Attaching a propeller imposes an aerodynamic load, so the no-load estimate cannot be treated as a thrust prediction. A motor with the same KV as another can have different dimensions, thermal limits and allowable combinations. Students should identify which questions a speed constant answers and which require separate data, such as current, power or tested thrust under stated conditions.

Compare complete evidence rows

Create a table containing motor model, stated constant, permitted supply conditions, mass, documented propeller combinations and test-data source. Leave unknown cells visible. Two rows sharing the same KV value can still be very different candidates for a particular aircraft. A comparison should therefore discuss missing evidence instead of ranking products solely by a single familiar number.

Keep calculations separate from selection

The worksheet should end with a list of required documentation, not a component purchase instruction. Actual propulsion selection involves the entire power train, frame, installation and intended operating conditions. YANA has not confirmed a motor specification, so an educational example must not be presented as part of its final package. Keep that distinction visible when reviewing any proposed component list.

  • Write RPM per volt explicitly.
  • Label no-load arithmetic as a model.
  • Use complete motor and test documentation.
  • Do not infer thrust or power from KV alone.

Audit a one-number motor comparison

  1. Create two fictional motor cards with the same 800 RPM-per-volt notation but different masses and documented limits.
  2. Calculate the illustrative no-load speed at 10 volts and explain why both cards produce the same simple result.
  3. Ask which missing fields prevent a real propulsion decision.
  4. Rewrite a claim that the higher KV motor is automatically more powerful into a question that can be answered by evidence.

Questions

Does higher KV automatically mean more thrust?

No. Thrust depends on the complete motor, propeller, supply and operating conditions. KV alone does not establish it.

Can I multiply KV by voltage to predict actual flight RPM?

That gives only a simplified no-load-style comparison under assumptions. Loaded operating speed requires appropriate data for the actual system.
